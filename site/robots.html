Revoir un combat

Un combat lancé dans VS Code (python combat.py mur) est enregistré dans combat.json. Choisissez ce fichier : le combat se rejoue sur le ring.

Inscrire votre robot au championnat

Le robot envoyé est celui de l'onglet Programmer, pour la génération choisie. Vous pouvez le renvoyer : le formateur garde le dernier envoi.

Choisissez votre robot

Flèches pour parcourir, Entrée pour choisir, Échap pour fermer. Le robot ne change rien au combat : seulement son apparence.
